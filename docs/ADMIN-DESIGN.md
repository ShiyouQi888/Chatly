# 运营后台设计规范

后台继续使用现有 shadcn 风格的 Radix 组件，统一在 `html[data-app="admin"]` 下定义主题。普通用户端不继承这套主题。

## 配色

采用炭灰背景与薄荷绿主色。相较深色桌面技能的默认饱和绿色，将主色调整为 `#7ad7b1`，以适配长时间使用的运营界面；导航、主要操作、焦点与积极状态使用同一色系。

| 用途 | Token | 色值 |
| --- | --- | --- |
| 页面背景 | `--op-canvas` | `#101214` |
| 侧栏 | `--op-sidebar` | `#141619` |
| 卡片 | `--op-surface` | `#1a1d21` |
| 浮层/次级控件 | `--op-surface-raised` | `#22262b` |
| 边界 | `--op-line` | `#2c3137` |
| 标题与正文 | `--op-ink` | `#f0f3f5` |
| 次级文字 | `--op-secondary` | `#b8c0c8` |
| 辅助文字 | `--op-muted` | `#929da8` |
| 主要操作 | `--op-brand` | `#7ad7b1` |
| 危险操作 | `--op-danger` | `#f18e99` |
| 警告 | `--op-warning` | `#e9c489` |

## 字体、尺寸与布局

- 使用系统无衬线字体和中文回退。页面标题 28/36、700；卡片标题 16/24、650；正文 13/22；辅助信息 12/18。
- 间距遵循 4 px 节奏。卡片内边距 24，页面内边距 32，主要区块间距 24。
- 圆角：紧凑控件 8、卡片 12、弹窗 16。常规按钮/输入框高 40，紧凑表格按钮高 32。
- 侧栏宽 248，折叠后 80。页面主体最大宽度 1480；760 以下侧栏使用抽屉，内容单列。
- 表格共享工具栏、44 px 表头、16 px 行内边距、状态徽标与操作按钮。

## 组件与状态

主要操作使用薄荷绿实底；次级操作使用带边框的炭灰按钮；表格内危险操作使用浅红文字与透明红底，确认弹窗使用更显著的危险按钮。所有控件统一定义悬停、按下、键盘焦点和禁用状态。

图标统一使用 Lucide，常规 16/20 px；空状态使用单一内容隐喻与少量主色，不填充演示业务数据。成员页以列表为主体，新增账号使用聚焦弹窗，角色使用带说明的单选项。Radix 负责焦点锁定、Escape、下拉键盘操作与弹窗语义。

主题位于 `src/screens/admin-tailwind.css`，布局与组件状态位于 `src/screens/admin-console.css`。通过基础组件的 `data-slot`/`data-variant` 控制视觉，避免重复覆盖。浮层继承同一组根主题变量，并支持减少动态效果的系统偏好。
