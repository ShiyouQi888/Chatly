分级发现

P0
焦点态几乎不存在
全站 :focus-visible 仅 7 处、outline 声明 0 处。键盘用户无法感知焦点，违反 WCAG 2.4.7。
global.css · 修复：统一 :focus-visible { outline: 2px solid var(--focus-ring) }
P0
换肤不完整 + 浅色主题不可读
applyThemeColors 只改 9 个品牌变量；~490 处写死 hex 的元素不换肤。5 套主题 4 套按钮文字低于 4.5:1。
utils/theme.js:17-33 · data/themes.js · 引入 --brand-ink 或渐变遮罩
P1
间距系统完全缺失
零 --space-* 令牌；padding/margin/gap 覆盖 1–18px 每个整数，无栅格可言。
~800 处字面值 · 建议 4px 基准 --space-0..10
P1
字号刻度被 ~280 处字面 px 绕过
var(--fs-*) 用 433 处，但另混入 9/9.5/10/13/14/16/18… 等刻度外值；13 与 13.5 并存。
建议 7 阶字阶，禁刻度外 px
P1
缺 Button / Input 原语，按钮被重复实现 18 次
ui.jsx 无 Button；18 个 CSS 各自实现 .btn。ui.jsx 与 shadcn ui/badge 撞名 Badge。
components/ui.jsx · components/ui/badge.jsx
P1
无语义色令牌，危险红有 11 个近似值
#f04a5e/#e05252/#e34d59/#e8657f/#e8799b/#e53945/#e0455c/#ef4444… 同一"删除"语义四五种红。
chat-room.css:1291,1799,1859 · login.css:167,217
P1
z-index 无刻度，30 个散值
-1…160 之间 55/59/60/78/80/82/84/90/95/96/100/115/118/119 全是打补丁值，叠层难推理。
建议 6 级 --z-* 刻度
P2
圆角混入 14 种非刻度值 · 动效时长无令牌
圆角 5/7/9/10/11/13/14/15px 等；时长 0.12–0.3s + 120/140/180ms 混用，s/ms 不统一。
建议 --r-* 六档、--dur-fast/base/slow
