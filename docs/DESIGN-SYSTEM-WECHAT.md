# Chatly · 微信风格设计系统（WeChat Design System v1.0）

> ⚠️ **【参考基线 · 品牌色不采用】** 本文档只用于提炼微信的「标准化方法」。
> Chatly 正式采用的设计语言是 **`docs/DESIGN-SYSTEM-CHATLY.md`（CDLS）**：借微信的结构，用 Chatly 自己的紫蓝品牌。
> 请勿把微信绿 / 暖灰 / 红包橙直接用于产品。

> 依据 **Tencent/WeUI** 与微信设计语言整理，为 Chatly 提供一套可落地的令牌与组件规范。
> 配套文件：`docs/wechat-tokens.css`（令牌层）· `docs/wechat-design-system.html`（视觉规范页）

---

## 1. 设计哲学

微信的设计语言不是「绿色 App」，而是**克制到近乎没有设计**：

| 原则 | 含义 | 落地规则 |
|------|------|---------|
| **克制** | 颜色越少，每种颜色的语义越重 | 大面积白与浅灰承载界面；品牌绿只出现在「确认/完成」；橙金色只属于钱 |
| **效率** | 一屏一件事，操作集中在中下部 | 导航 44 / 单元格 56 / TabBar 50，单手可达 |
| **真实** | 层级来自字号与灰度，不靠装饰 | 加粗只给关键信息；不堆阴影、不堆渐变（品牌绿尤其不用渐变） |
| **统一** | 一个组件只有一种样子 | 同类交互用同一组件，禁止各屏自写按钮 |

> 一句话记法：**看到绿色 = 可以确认；看到橙色 = 和钱有关；看到红色 = 小心。**

### 2.2 使用纪律

- **品牌绿不得作大面积背景**，也不得用于危险操作（危险只能用 `--wx-danger`）。
- **橙金色专属于金额**（红包、转账），不得用于普通强调。
- 同一屏**只保留一个主强调色**；链接用 `--wx-link`，不要用绿色冒充链接。

## 3. 字体系统

```css
--wx-font: -apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans SC",
           "Source Han Sans SC", "Microsoft YaHei", sans-serif;
--wx-lh: 1.41176471;   /* 24 / 17，微信标准行高 */
```

| 令牌 | 字号 / 字重 | 用途 |
|------|------------|------|
| `--wx-fs-display` | 28 / 600 | Hero 标题 |
| `--wx-fs-heading` | 20 / 600 | 章节标题 |
| `--wx-fs-title` | 17 / 600 | 导航标题、会话名 |
| `--wx-fs-body` | 17 / 400 | **正文基准** |
| `--wx-fs-footnote` | 14 / 400 | 辅助说明 |
| `--wx-fs-caption` | 12 / 400 | 时间戳、角标 |

> 层级靠字号 + 灰度表达；`font-weight` 只用 400 / 500 / 600 三档，600 只给关键信息。

## 4. 间距 · 圆角 · 骨架

### 4.1 间距（4px 基准）

`--wx-space-1..8` = `2 / 4 / 8 / 12 / 16 / 20 / 24 / 32`。页面与卡片标准内边距 **16px**，紧密图标间距 **≥8px**。

### 4.2 圆角（偏「方」）

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--wx-r-xs` | 4px | 头像（**圆角方形，非圆形**）、小标签 |
| `--wx-r-sm` | 6px | 小输入、搜索 |
| `--wx-r-md` | 8px | 按钮、输入框、搜索栏 |
| `--wx-r-lg` | 12px | 卡片、对话框 |
| `--wx-r-xl` | 16px | 半屏浮层顶角 |

### 4.3 布局骨架

| 令牌 | 值 | 说明 |
|------|-----|------|
| `--wx-navbar-h` | 44px | 导航栏（不含状态栏，真机用 safe-area 动态补） |
| `--wx-tabbar-h` | 50px | 底部 TabBar |
| `--wx-cell-h` | 56px | 标准单元格 |
| `--wx-cell-px` | 16px | 单元格左右内边距 |
| `--wx-tap-min` | 44px | 最小触控目标 |

> 分隔线统一 `1px` + `transform: scaleY(.5)` 或 `border: .5px`，颜色 `--wx-line`；单元格分隔线**左侧内缩 16px**（微信特征）。

### 4.4 阴影

极简：卡片 `--wx-shadow-card`（几乎不可见的 1px 底阴影），只有浮层用 `--wx-shadow-sheet: 0 -4px 24px rgba(0,0,0,.12)`。

## 5. 组件规范

### 5.1 导航栏 NavBar
- 高 44px，背景 `--wx-bg-1`，标题 17/600 **居中**。
- 左：返回 chevron（24px）；右：文字动作 `--wx-brand` 或更多图标。
- 真机必须用 `safe-area-inset-top` 补齐状态栏，**不要写死总高度**。

### 5.2 底部 TabBar
- 高 50px，图标 22px + 文字 10px。
- 选中 `--wx-icon-active`，未选中 `--wx-icon`；角标用 `--wx-danger`。

### 5.3 单元格 Cell
- 高 56px，左右 16px，左侧主文案 17px，右侧值 15–17px `--wx-text-2`。
- 右侧 chevron 16px `--wx-text-3`；分隔线左缩 16px、0.5px。

### 5.4 聊天气泡 Bubble
- 对方：白底 `--wx-bubble-in`；己方：`--wx-bubble-out`。
- 文字恒为深色 `--wx-text-1`；圆角 **4px** + 6px 三角小尾巴。
- 最大宽度 **72%**；时间分隔居中 12px `--wx-text-3`。
- 头像 **圆角方形 4px**（38–44px），这是微信与多数 IM 的差异点。

### 5.5 按钮 Button
| 类型 | 背景 | 文字 | 场景 |
|------|------|------|------|
| 主按钮 | `--wx-brand` | 白 | 一屏一个核心操作 |
| 默认 | 白 + 1px `--wx-line-strong` | `--wx-text-1` | 次要操作 |
| 危险 | `--wx-danger` | 白 | 删除/不可逆 |
| 文字 | 透明 | `--wx-link` | 轻量动作 |
| 禁用 | `#E6E6E6` | `--wx-text-disabled` | 不可用 |

规格：高 **48**、圆角 **8**、字号 **17**、最小宽度 184。

### 5.6 输入框 / 搜索
- 输入框高 44，圆角 8，底 `--wx-bg-1`，占位 `--wx-text-3`。
- 搜索栏高 32–36，圆角 6–8，白底或浅灰底 + 放大镜 15px。

### 5.7 头像 Avatar
- **圆角方形 4px**；尺寸 28 / 36 / 44 / 56。
- 群头像可用九宫格拼贴；角标用 `--wx-danger` 圆形/红点。

### 5.8 开关 Switch
- 51×31，开启 `--wx-brand`，关闭 `#E5E5E5`，白色圆钮 27px + 轻微阴影。

### 5.9 对话框 Dialog
- 宽 280 / 屏宽 80%，圆角 12，标题 17/600，正文 14 `--wx-text-2-aa`。
- 按钮 52px 高，1px 分隔；主操作 `--wx-brand`，删除操作 `--wx-danger`。

### 5.10 轻提示 Toast
- `rgba(0,0,0,.72)` 底、白字、圆角 8、最大宽 200、居中；1.5–2s 自动消失。
- **不承载需要决策的内容**（那是 Dialog 的职责）。

### 5.11 动作面板 ActionSheet
- 从底部滑入，白底，顶角圆角 16；选项单元格 56px；取消项与选项之间留 **8px 灰缝**。

## 6. 动效

```css
--wx-ease: cubic-bezier(.25,.1,.25,1);
--wx-dur-fast: 160ms;  --wx-dur: 200ms;  --wx-dur-slow: 300ms;
```

- 常规过渡 200ms；浮层上滑 300ms；按压反馈 160ms。
- 尊重 `prefers-reduced-motion`：已在令牌文件中关闭动效。

## 7. 可访问性（诚实说明）

微信本身在可访问性上有取舍，本系统在「还原」与「达标」之间给出明确边界：

1. **`#888888` 次级文字只有 3.5:1，不达 AA 4.5:1。**
   - 追求还原：装饰性说明可保留 `#888`。
   - **用户必须读的正文级次要文字：改用 `--wx-text-2-aa`（#6E6E6E，白底 5.1:1）。**
2. **品牌绿 `#07C160` 上压白字 3.0:1**，只够「大字/图标」3:1 门槛。
   - 主按钮字号 ≥18.66px 加粗，或改用深一档绿（`#059A4C` 白字 4.6:1）。
3. **焦点环**：微信原生几乎无键盘焦点反馈。本系统补 `:focus-visible { outline: 2px solid var(--wx-focus-ring) }`——这是对「标准化」的必要偏离，**不要删**。
4. **触控目标 ≥44×44**（`--wx-tap-min`）。

## 8. 接入 Chatly 的三种方式

### 8.1 作用域试用（零风险，推荐先做）
```html
<div class="wx-theme"> … </div>
```
`docs/wechat-tokens.css` 同时挂在 `:root` 与 `.wx-theme` 上，先给某个页面套 `.wx-theme` 验证观感，不影响现有紫蓝主题。

### 8.2 接成可切换主题（与现有「极光/海盐/暮色/云朵/午夜」并列）
在 `src/data/themes.js` 增加一组 `微信绿`，但**现有 `applyThemeColors` 只改 9 个品牌变量**，不足以切换整套中性色/圆角/字号。需要扩展 `theme.js`：把 `--bg/--surface/--text-*/--r-*/--fs-*` 也纳入可切换集合，或改为「主题 = 一整组 CSS 变量」。

### 8.3 全局替换
把 `tokens.css` 的令牌值按 §2–§4 全部替换为微信值，并删除 `--brand-grad` 的渐变用法。改动面最大，需回归全部 `check-*` 与 `audit-ui`。

### 8.4 与现有令牌的映射

| Chatly 现有 | 微信 | 值 |
|-------------|------|-----|
| `--brand-1/2/3` | `--wx-brand` | `#07C160` |
| `--brand-grad` | 纯色 | `#07C160` |
| `--bg` | `--wx-bg` | `#EDEDED` |
| `--surface` | `--wx-surface` | `#FFFFFF` |
| `--text-1` | `--wx-text-1` | `#191919` |
| `--text-2` | `--wx-text-2-aa` | `#6E6E6E` |
| `--text-3` | `--wx-text-3` | `#B2B2B2` |
| `--line` | `--wx-line` | `rgba(0,0,0,.1)` |
| `--r-md` 16 | `--wx-r-md` | 8px |
| `--fs-body` 15 | `--wx-fs-body` | 17px |
| `--font`（Noto 450） | `--wx-font` | 系统字 400 |

## 9. Do / Don't

| ✅ Do | ❌ Don't |
|------|---------|
| 大面积白/浅灰，绿色只用于确认 | 整屏绿色背景、品牌渐变 |
| 头像圆角方形 4px | 头像做成圆形 |
| 分隔线 0.5px、左缩 16px | 粗描边、满宽黑线 |
| 正文 17px、层级靠灰度 | 到处加粗、用颜色代替层级 |
| 一屏一个主按钮 | 多个绿色按钮抢焦点 |
| 危险操作红色 | 用绿色表示删除/危险 |
| 金额才用橙金 | 橙金当普通强调色 |
