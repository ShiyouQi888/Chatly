# Chatly Design Language System (CDLS) v1.0

> **借微信的标准化，用 Chatly 自己的气质。** 不采用微信任何品牌色。
> 配套：`docs/chatly-tokens.css`（令牌层）· `docs/chatly-design-system.html`（视觉规范页）

> **实施状态（2026-10-22）**：本文是目标规范，不代表全部已进入运行时代码。当前 App 仍加载 `src/styles/tokens.css`，没有导入 `docs/chatly-tokens.css`；该 CSS 含 `--cl-*` 令牌和旧名称映射，但尚未接入运行时。完整暗色模式和组件规格仍需按 §8 迁移。后台有独立的暗色主题。

## 0. 定位：我们向微信学什么、不学什么

| 继承：微信的**标准化结构** | 不借：微信的**品牌与色相** |
|---|---|
| 中性面三层承载界面，品牌色只做「动作/确认」 | 微信绿 `#07C160`、己方气泡 `#95EC69` |
| 语义色一色一义（危险/成功/警告/信息） | 暖灰 `#EDEDED` / `#F7F7F7` 的色温 |
| 链接色独立于动作色 | 红包橙金 `#FA9D3B` |
| 4px 栅格；页面 16 / 单元格 56 / 触控 44 | 系统字 400 的字体策略 |
| 固定字阶，层级靠字号与字重 | 4px 方角 |
| 状态齐备、极简阴影 | 几乎为零的 elevation |

**Chatly 自己的基因**：紫蓝品牌（`#6D5DF6`）、冷灰带紫调的中性面、Noto Sans SC 正文 **450**、柔和圆角（8–28）、柔和紫调投影、圆角方形（squircle）头像。

## 1. 设计原则

1. **一面一义**：每个表面层级只承担一种角色，不为装饰加层级。
2. **一色一用**：品牌紫只表达「动作/确认」；危险只用红；链接用独立靛蓝。
3. **克制加粗**：层级来自字号与字重，450 是正文，600 只给标题。
4. **有限刻度**：间距 11 档、圆角 6 档、字阶 8 档、层级 7 档——有限才可维护。
5. **AA 起步**：正文、说明、占位符等可读文字至少 4.5:1；非文本装饰令牌单独标注，不用于承载信息。

## 3. 字体系统

```css
--cl-font: "Noto Sans SC","Source Han Sans SC","PingFang SC","Microsoft YaHei", …;
--cl-fw-body: 450;   /* Chatly 签名：正文不用 400 */
```

| 令牌 | 字号/字重 | 用途 |
|---|---|---|
| `--cl-fs-display` | 30 / 700 | Hero |
| `--cl-fs-heading` | 24 / 600 | 章节标题 |
| `--cl-fs-title` | 20 / 600 | 页面/弹窗标题 |
| `--cl-fs-subtitle` | 17 / 500 | 会话名、列表主文案 |
| `--cl-fs-body` | 15 / 450 | **正文基准** |
| `--cl-fs-footnote` | 14 / 450 | 辅助说明 |
| `--cl-fs-caption` | 12 / 450 | 时间戳、角标 |
| `--cl-fs-micro` | 11 / 500 | 微标签（下限，禁止更小） |

行高：标题 `--cl-lh-tight 1.3`，正文 `--cl-lh-base 1.5`，长文 `--cl-lh-relaxed 1.65`。全部字号乘 `--cl-font-scale`（字号设置）。

## 4. 间距 · 圆角 · 阴影 · 骨架

### 4.1 间距（4px 基准，仅 11 档）
`--cl-space-0..10` = `0 / 2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。页面与卡片标准内边距 **16**。

### 4.2 圆角（柔和，全部 4 的倍数）
| 令牌 | 值 | 用途 |
|---|---|---|
| `--cl-r-xs` | 8 | 小标签、输入内元素 |
| `--cl-r-sm` | 12 | 按钮、输入、Toast |
| `--cl-r-md` | 16 | 卡片、对话框 |
| `--cl-r-lg` | 20 | 大卡片、浮层 |
| `--cl-r-xl` | 28 | 半屏面板顶角 |
| `--cl-r-full` | 999 | 胶囊/圆形 |

头像：**圆角方形 squircle**，半径 = `size / 3`（28→9、44→15、56→18），延续现有实现。

### 4.3 阴影
| 令牌 | 用途 |
|---|---|
| `--cl-shadow-1` | 卡片静置 |
| `--cl-shadow-2` | 浮起/下拉 |
| `--cl-shadow-3` | 模态/弹窗 |
| `--cl-shadow-brand` | 品牌按钮投影（紫调） |

### 4.4 骨架
| 令牌 | 值 |
|---|---|
| `--cl-nav-h` | 44px |
| `--cl-tabbar-h` | 58px |
| `--cl-cell-h` | 56px |
| `--cl-page-px` | 16px |
| `--cl-tap-min` | 44px |

分隔线统一 1px + `scaleY(.5)`，单元格分隔线**左侧内缩 52px**（图标列宽）。

| 状态 | 处理 |
|---|---|

| Hover | brand-500 → brand-600 / 表面 +1 层 |

## 7. 可访问性

- **对比度目标**：正文、次级文字、占位符和链接至少 4.5:1；非文本图标至少 3:1。暗色主题逐对前景/背景复核。
- **使用边界**：`brand-400` 仅用于满足非文本图标或大字对比度的场景；`text-4` 仅用于非文本装饰；按钮底默认用 `brand-600`。
- **焦点**：使用 `:focus-visible` 2px 焦点环。当前 `src/styles/global.css` 已有基础焦点样式；接入 CDLS 后须映射到 `--cl-focus-ring` 并复核后台门户。
- **触控**：`--cl-tap-min: 44px`。
- **动效**：`prefers-reduced-motion` 全关。

| `--line` | `--cl-line` | 同语义 | — |
| `--r-lg` 22 | `--cl-r-lg` | 20 | 回网格 |
| `--fs-body` 15 | `--cl-fs-body` | 15 | 保留 |
| `--font` | `--cl-font` | 同 | 保留 450 |
| `--space-*` / `--z-*` / `--dur-*` | `--cl-space-*` / `--cl-z-*` / `--cl-dur-*` | 已有对应刻度 | 运行时名称不同；迁移时建立映射并逐步替换 |
| （缺） | `--cl-danger/success/warning/info` | 新增 | 补充 App 语义色令牌 |
| （缺） | `[data-theme="dark"]` | 新增 | 暗色令牌目前只在配套文档 CSS 中定义，App 尚未接入 |

### 落地步骤（建议顺序）

1. **先修文字用途**：运行时 `--text-3` 已达到目标；把被当作正文使用的 `--text-4` 替换为可读的 `--text-muted`。主题主按钮使用 `#5B4BD8`。
2. **接入令牌映射**：运行时已有间距、层级、时长刻度；配套 CSS 已定义 `--cl-*` 与旧名称的桥接，合并到运行时前需核对重复定义和主题行为，再逐屏替换散落的字面值。
3. **逐屏替换**：每屏把字面 px 吸附到 `--cl-space-*` / `--cl-fs-*` / `--cl-r-*`，替换后跑 `check-parse` + 对应 `check-*`。
4. **接暗色**：给 App 实现 `data-theme="dark"` 切换并验证所有屏；仅有文档 CSS 定义不代表功能已上线。
5. **收口旧别名**：删 `--brand-*` 与 `--primary*` 双写。

## 9. Do / Don't

| ✅ | ❌ |
|---|---|
| 中性面承载界面，紫只做动作 | 大面积紫色背景、到处紫 |
| 正文 450、标题 600 | 全篇加粗、用颜色代替层级 |
| 按钮底 brand-600 | 按钮底用 brand-200/渐变 |
| 危险用 `--cl-danger` | 用品牌紫表示删除 |
| 链接用 `--cl-link` | 用品牌紫冒充链接 |
| 间距吸附 11 档刻度 | 写 5/7/9/13px 这类散值 |
| 圆角 8/12/16/20/28 | 混入 10/14/18/22px |
