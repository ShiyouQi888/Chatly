Design Language System · v1.0

Chatly Design Language

我们不采用微信的配色，但完整继承它的标准化方法：中性面承载界面、单一强调色只管动作、语义色一色一义、4px 栅格、固定字阶、克制的阴影。品牌与气质回到 Chatly 自己——紫蓝、冷灰、Noto Sans SC 450、柔和圆角。

结构 · 学微信的纪律
气质 · 是 Chatly 自己
对比度 · 全部 AA 起步
暗色 · 一等公民

00借与不借

把「可迁移的方法」和「不可迁移的品牌」分开，是这套系统成立的前提。

继承：微信的标准化结构

  • 中性面三层承载界面，品牌色只做「动作 / 确认」
  • 语义色一色一义：危险/成功/警告/信息 各有专属
  • 链接色独立于动作色（链接 ≠ 主按钮）
  • 4px 栅格；页面 16 / 单元格 56 / 触控 44
  • 固定字阶，层级靠字号与字重，不靠装饰
  • 状态齐备：默认 / 悬停 / 按压 / 禁用 / 焦点
  • 极简阴影，浮层才有 elevation

不借：微信的品牌与色相

  • 微信绿 #07C160、己方气泡 #95EC69
  • 暖灰 #EDEDED / #F7F7F7 的色温
  • 红包橙金 #FA9D3B 的专属语义
  • 系统字 400 的字体策略（我们用 Noto 450）
  • 4px 方角（我们用 8–28 的柔和圆角）
  • 几乎为零的阴影（我们用柔和紫调投影）

08可访问性 · 目标规范

对比度目标：正文 16.5 / 次级 8.1 / 三级 4.8 / text-muted 4.8 / 动作按钮白字 6.10 / 链接 6.5 / 语义文字 5.0–6.4。text-4（#9a9ab0）仅用于非文本装饰，不用于占位、时间或标签。
使用边界：brand-400 仅用于通过对比度检查的非文本图标或大字；可读文字达到 4.5:1；动作按钮默认用 brand-600。
焦点与触控：目标为统一 :focus-visible 焦点环和 44×44 最小触控区，并尊重 prefers-reduced-motion。此页是规范示例，不表示这些规格都已进入 App。
