Design System · WeChat Language · v1.0

微信风格设计系统

以 Tencent/WeUI 与微信设计语言为基准，为 Chatly 定义一套可落地的令牌与组件规范。核心不是「做成绿色」，而是克制：大面积白与浅灰把舞台让给内容，品牌绿只表达「确认与完成」，橙金色只属于钱。

克制 · 颜色越少，语义越重
效率 · 一屏一件事，操作集中中下部
真实 · 层级来自字号与灰度，不靠装饰
统一 · 一个组件只有一种样子

01色彩系统

三层逻辑：中性灰承载界面 · 品牌绿只表达确认 · 功能色各自独占语义。品牌绿不得用于大面积背景，也不得用于危险操作。

06可访问性：在「像微信」与「能读懂」之间

微信原值 #888888 的字面次级文字只有 3.5:1，不满足 WCAG AA 4.5:1。这是微信本身的选择，不是本系统的疏漏。做法：追求还原时保留 #888 用于装饰性说明；凡是用户必须读的正文级次要文字，改用 --wx-text-2-aa（#6E6E6E，白底 5.1:1）。
品牌绿 #07C160 上压白字只有 3.0:1，仅够「大字/图标」的 3:1 门槛，不够正文 4.5:1。因此：主按钮要么字号 ≥18.66px 加粗（微信实际就是 17px 大字场景），要么把按钮改为深一档的绿（如 #059A4C，白字 4.6:1）。
焦点环：微信原生几乎无键盘焦点反馈。本系统补了 :focus-visible { outline: 2px solid var(--wx-focus-ring) }，这是对「标准化」的必要偏离，不建议删。
