# 连接更有趣的人， 界面要先让人放松。

Chatly 的设计语言围绕一件事：让对话本身成为主角。轻的表面、克制的细线、一抹紫色的动作色，以及每个控件背后都有真实数据的诚实感。

页面里的所有色值都是实时令牌，切换主题与明暗，右侧预览和下方规范同步变化。

## 设计原则

四条原则决定了每一次取舍。

**可追溯**界面上的每个数字、每句话、每次点击都对应一行真实数据。接不上的功能显示“未接入”并禁用，不做点了弹提示假装成功的按钮。

**轻**用 1px 分隔线和表面层级区分内容，不叠加重阴影。只有浮层（面板、菜单、弹窗）才有投影。

**对比先行**承载白字的颜色一律使用满足 WCAG AA（4.5:1）的深端色值；次要文字不低于 11px。

**动效只回应操作**动效短而轻，只用来说明“刚才发生了什么”，并尊重系统的“减少动态效果”设置。

## 色彩

一个品牌动作色，四个只用于状态的强调色，其余是安静的中性色。

### 品牌色（随主题变化）

**primary**\
渐变起点、图标、链接

**primary-end**\
实心按钮、我方气泡、开关

**brand-gradient**`135°`\
主按钮、我方消息

**primary-soft**`14% 透明`\
标签、选中底色

### 强调色（仅表达状态与内容，不做按钮底色）

**青蓝 cyan**`#39c9f5`\
链接、信息提示

**薄荷 mint**`#34d3a6`\
在线、成功

**粉 pink**`#f97ca8`\
点赞、情感内容

**琥珀 amber**`#ffb43f`\
提醒、待处理

### 中性色

**canvas**\
页面底，暖白

**surface**\
内容面、浮层

**input**\
输入框、次按钮

**line**\
分隔线

**text-1**\

**text-2**\
次级信息

**text-3**\

**text-4**\

## 字体

Noto Sans SC（思源黑体），正文字重 450 起。字号以 15px 为正文，时间与状态不小于 11px，并随“字体大小”设置整体缩放。

| 角色 | 字号 / 行高 / 字重 | 样例 |
| --- | --- | --- |
| 页面标题 | 28 / 36 / 700 | 我的动态 |
| 栏目标题 | 20 / 28 / 700 | 群公告 |
| 列表标题 | 16 / 24 / 500 | 林小满 |
| 消息正文 | 15 / 22 / 450 | 周末的露营你去吗？ |
| 次级信息 | 13 / 18 / 450 | 昨天 21:08 · 已读 |
| 时间与徽标 | 11 / 14 / 450 | 下午 3:42 |

中文不使用全大写与字距拉伸；行长控制在 36 个汉字以内，段落首行不缩进。

## 间距与形状

4pt 网格。圆角、阴影、层级各自只有少数几档，选错一档比多一档更容易让界面发散。

### 间距

4 · 图标与文字

8 · 紧凑元素间

12 · 列表行内边距

16 · 页面左右边距

24 · 分组间距

32 · 区块间距

### 圆角

8 · 小按钮、标签

12 · 按钮、输入框、卡片

18 + 6 · 消息气泡（尾角 6）

999 · 头像、胶囊、徽标

### 层级

E0 · 分隔线，内容面

E1 · 对方气泡

E2 · 面板、菜单、弹窗

布局：竖屏固定，桌面预览宽 390px 居中；≤440px 铺满视口。点击目标不小于 44×44px。

### 消息

| 类型 | 规则 |
| --- | --- |
| 文字 | 我方：品牌渐变 + 主题文字色，尾角在右下；对方：bubble-in 面 + E1，尾角在左下。最大宽度 78%。 |
| 引用回复 | 气泡内顶部放 2px 左线引用条，12px，不透明度 80%；点击引用条跳转并高亮原消息。 |
| 撤回 | 居中灰字“你撤回了一条消息”，11–13px，text-3。 |
| 大表情 | 96×96，无气泡无边框。 |
| 状态 | 发送中、已送达、已读使用 11px text-3 文字，不用颜色单独表达。 |

### 底部导航

五个板块：聊天 / 通讯录 / 动态 / 社群 / 我。选中态同时改变颜色和图标描边，不只靠颜色。

## 动效

短、轻、有缓出。点击下面的方块感受三档时长。

缓动 cubic-bezier(.2,.8,.2,1)。长按手势 480ms 触发，容差 10px，触发时给振动反馈。开启“减少动态效果”或应用内“动效开关”关闭时，位移与缩放全部退化为即时变化。

## 文案与语气

朋友式的平实语气：用户视角、主动语态、句首大写式（中文即不加修饰）。错误说明原因和下一步，不道歉；空状态是一次邀请。

**应该这样**

保存修改 → 已保存\
网络已断开，连上后会自动重发\
还没有好友，扫一扫或输入 ID 添加

**避免这样**

确定 → 操作成功\
哎呀，出错了！抱歉给您带来不便\
暂无数据

## 设计令牌

可直接放进 `src/styles/tokens.css`。聊天界面通过 `--chat-*` 语义令牌映射到这些基础令牌。

```
:root {
  /* 品牌（主题切换时改写） */
  --primary:#6d5df6; --primary-end:#5b4bd8; --on-primary:#fff;
  /* 强调（仅状态与内容） */
  --cyan:#39c9f5; --mint:#34d3a6; --pink:#f97ca8; --amber:#ffb43f; --danger:#e5484d;
  /* 表面与文字 */
  --canvas:#f7f7fb; --surface:#fff; --input:#f0f0f6; --line:#ececf3;
  --text-1:#1a1a2e; --text-2:#55556b; --text-3:#6f6f86; --text-4:#b5b5c6;
  /* 聊天语义 */
  --chat-bg:var(--canvas); --chat-surface:var(--surface); --chat-input:var(--input);
  --chat-divider:var(--line); --chat-out-bg:linear-gradient(135deg,var(--primary),var(--primary-end));
  --chat-out-text:var(--on-primary); --chat-in-bg:#fff; --chat-in-text:var(--text-1);
  /* 形状与层级 */
  --r-s:8px; --r-m:12px; --r-l:18px; --r-pill:999px;
  --e1:0 1px 2px rgba(26,26,46,.06); --e2:0 8px 24px rgba(26,26,46,.10);
  /* 字体与动效 */
  --font:"Noto Sans SC","PingFang SC",system-ui,sans-serif; --font-scale:1;
  --ease:cubic-bezier(.2,.8,.2,1); --d-fast:120ms; --d-base:200ms; --d-slow:320ms;
  --safe-top:env(safe-area-inset-top,0px);
}
/* 深色：canvas #101018 / surface #1a1a26 / input #242434 / line #2a2a3a
         text-1 #f2f2f8 / text-2 #b4b4c8 / text-3 #9a9ab0 / chat-in-bg #242434 */
```
