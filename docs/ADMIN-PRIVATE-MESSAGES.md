# 后台私聊查阅

管理台的“私聊查阅”支持检索私聊会话、填写原因后分页读取消息正文。使用独立后台会话认证及 `messages.private.read` 权限；当前仅超级管理员拥有该权限，内容审核、客服运营、数据分析与普通用户均不可调用。

## 接口

- `GET /api/v1/admin/private-conversations?q=&page=1&limit=20`：按参与人昵称、账号、用户 ID 或会话 ID 检索。可选 `userId` 精确限定参与人。只返回参与人、消息数与时间，不返回正文或预览。
- `POST /api/v1/admin/private-conversations/:id/messages/read`：请求体 `{ "reason": "核查工单 #123", "limit": 50, "beforeId": 100 }`。原因须为 2–300 个字符；`beforeId` 为可选的上一页游标；单次最多 100 条。返回按消息 ID 升序排列的记录、下一页游标及查阅时间。

每次列表检索记录 `private.conversations.list`，每页正文读取记录 `private.messages.read`。日志包含后台账号、原因、会话、返回的消息 ID、数量、时间与分页条件，不包含正文、密文或密钥。正文读取在数据库事务中写入审计，事务提交成功后才返回数据；审计失败时不会返回正文。响应使用 `Cache-Control: private, no-store`。

## 消息处理

- 已撤回消息仅显示撤回状态；已到期的阅后即焚消息不会返回。已清除的消息不会恢复。
- 当前消息加密是服务端 AES-256-GCM 存储加密，配置正确的 `MESSAGE_ENCRYPTION_KEY` 时可以按权限解密。密钥缺失、错误或密文损坏时，仅返回不可读取状态，密文不会作为正文或错误信息输出。
- 查阅不会修改用户已读状态、发送已读回执或启动阅后即焚计时。
- 图片、视频、文件、语音与位置消息仅显示类型和必要的文件名称、大小信息。该接口不提供附件地址、下载或精确位置。
- 页面关闭查阅窗口时清除正文状态，正文不写入浏览器本地存储。

相关行为由 `scripts/check-admin-auth.mjs` 中的隔离数据库回归覆盖。
